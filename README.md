# DEMON Top Up Haïti V1

Projet Flutter de démonstration avec:
- Mobile Top Up (Digicel / Natcom)
- Game Top Up
- Netflix
- Paiement MonCash / NatCash (interface démo)
- Historique
- Profil
- Notifications / Paramètres (interface)

Important: les paiements et recharges réels nécessitent un backend et les APIs/autorisation des fournisseurs.

Build Android:
flutter pub get
flutter build apk --release
